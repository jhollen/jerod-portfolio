# Portfolio: Audio Compressor UI

## The Vision
This portfolio is a technical exploration of skeuomorphic design, modeled after the professional Logic Pro audio compressor. The goal was to bridge the gap between tactile hardware and digital interfaces, creating a "hands-on" experience for visitors while showcasing advanced CSS and animation techniques.

## Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion (used for realistic knob and slider physics)
* **Deployment:** Vercel

## Key Features
* **Interactive Hardware UI:** Custom-built components that mimic real-world audio gear interaction.
* **Dynamic State Management:** Handling complex UI states seamlessly across the portfolio.
* **Performance Optimized:** High-quality visuals with a focus on fast load times and responsive design.
* **Mise en Place Architecture:** Organized with a "prep-first" philosophy—clean, modular, and maintainable code.

## Technical Challenge
Implementing hardware-style knobs and sliders in a browser requires precise event handling and physics. I utilized Framer Motion to ensure every interaction felt weighted and intentional, providing a tactile feel that standard digital inputs lack.
